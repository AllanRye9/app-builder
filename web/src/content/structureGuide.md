## Web / Capacitor project

- `package.json` at the archive root
- No `android/`, `ios/`, or `platforms/` folder — those are generated by the build
- A `capacitor.config.json`/`.ts` is optional — reused if present, created if not

## Native Android project

- `settings.gradle` (or `.kts`) and a root `build.gradle` (or `.kts`)
- The complete Gradle wrapper: `gradlew`, `gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar`, `gradle/wrapper/gradle-wrapper.properties`
- Run `gradle wrapper` before zipping if any of those are missing

## Archive rules

- One project per `.zip`, up to **300 MB** — several archives can be dropped at once
- A single top-level wrapper folder (e.g. `my-app/`) is fine — it's auto-flattened
- Path traversal, absolute paths, and null bytes in entry names are rejected outright

## Allowed file types

Anything else (editor/OS cruft, license files, unrecognized binaries) is silently skipped rather than failing the upload — you'll see what got left out in the build log.

| Category | Extensions |
| --- | --- |
| Code | `.js` `.jsx` `.ts` `.tsx` `.mjs` |
| Config | `.json` `.yml` `.lock` |
| Styles | `.css` `.scss` `.less` |
| Docs | `.html` `.md` `.txt` |
| Media | `.png` `.jpg` `.svg` `.webp` |
| Fonts | `.woff` `.ttf` |
| Native | `.kt` `.java` `.gradle` `.xml` |
