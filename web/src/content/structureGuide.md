## Web / Capacitor project

- `package.json` at the archive root
- No `android/`, `ios/`, or `platforms/` folder — those are generated by the build
- A `capacitor.config.json`/`.ts` is optional — reused if present, created if not

## React Native project

- `package.json` at the archive root, with `react-native` listed under `dependencies` or `devDependencies` — that's the one signal used to tell this apart from a plain web/Capacitor project
- Its own `android/` folder **is required** and must include the complete Gradle wrapper (`android/gradlew`, `android/gradlew.bat`, `android/gradle/wrapper/gradle-wrapper.jar`, `android/gradle/wrapper/gradle-wrapper.properties`) — unlike Flutter, this is never generated for you
- `ios/` is allowed alongside it (only `android/` is ever built into an APK here)
- The JS bundle and assets are produced with `react-native bundle --dev false` before Gradle runs, so the resulting debug APK doesn't need a Metro dev server to launch
- `index.js`, `index.ts`, or `index.tsx` at the project root is used as the entry file

## Native Android project

- `settings.gradle` (or `.kts`) and a root `build.gradle` (or `.kts`)
- The complete Gradle wrapper: `gradlew`, `gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar`, `gradle/wrapper/gradle-wrapper.properties`
- Run `gradle wrapper` before zipping if any of those are missing

## Flutter project

- `pubspec.yaml` at the project root
- An `android/` folder is optional — generated automatically if missing, left untouched if you include your own
- `ios/` is allowed alongside it (only `android/` is ever built into an APK here)
- No Gradle wrapper required — `flutter build apk` manages its own embedded Android build

## Archive rules

- One project per `.zip`, up to **300 MB** — several archives can be dropped at once
- The project doesn't need to sit at the archive root — a wrapper folder, or several nested folders, are fine and auto-detected
- Path traversal, absolute paths, and null bytes in entry names are rejected outright

## Allowed file types

Anything else (editor/OS cruft, license files, unrecognized binaries) is silently skipped rather than failing the upload — you'll see what got left out in the build log.

| Category | Extensions |
| --- | --- |
| Code | `.js` `.jsx` `.ts` `.tsx` `.mjs` |
| Config | `.json` `.yml` `.lock` |
| Styles | `.css` `.scss` `.less` |
| Docs | `.html` `.md` `.txt` |
| Media | `.png` `.jpg` `.svg` `.webp` |
| Fonts | `.woff` `.ttf` |
| Native | `.kt` `.java` `.gradle` `.xml` |
| Flutter | `.dart` `.arb` |
